# Security reporting

Use the repository's private vulnerability reporting in GitHub's Security tab. Do not post credentials, exploit details or user data in public issues. If private reporting is unavailable, use https://talkytalky.im/help.html to request a private channel.

This repository contains client code. Signing material, backend deployment credentials and private Git history are excluded. Public upstream cryptographic test vectors and test-only keys may trigger scanners; they are not production credentials and must never be reused as such. Security scans and build checks do not guarantee that the client is free of security issues.
