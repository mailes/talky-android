# Contributing

Keep pull requests focused and explain the problem and the resulting behaviour. Include the checks you ran; visual changes need actual screenshots or recordings. Bug reports should include Android version, device and a minimal reproduction.

Use English for new code comments and logs, keep user-facing text in localization resources, and preserve existing copyright and dependency notices. Contributions are offered under the applicable project license without a separate license agreement.

Never commit private-build.properties, signing keys, signing passwords, service project files, production tokens, generated packages or private conversations. Do not switch a release to a new signing identity merely to make a build pass.
